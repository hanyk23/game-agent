1.1 智能体结构设计
结构设计
当前成果
未来工作

项目目标不是手工制作单个游戏，而是构建一个能生成竖版弹幕 H5 游戏的 AI Agent。

Layer 01

需求与决策层

把自然语言需求转换成结构化 Spec，并判断需求是否在项目目标和模块能力范围内。

Layer 02

生成与组合层

根据 Spec 匹配模块库；必要时由 OpenCode 辅助生成候选模块、连接代码或修复代码。

Layer 03

运行与验证层

通过 runtime kernel 接入 Phaser，并用自动化测试、浏览器验证和打包校验进行质量把关。

1.2 智能体工作流程
结构设计
当前成果
未来工作

整体流程采用“模型辅助决策 + 程序确定性校验”的方式，降低生成过程的不稳定性。

用户需求输入游戏主题、玩法、敌人、弹幕和目标。
生成 Spec把自然语言整理成机器可读取的结构化规格。
匹配模块从模块库中选择玩家、敌人、弹幕、得分等能力。
OpenCode在受控范围内补充代码、适配代码或修复失败。
Phaser 运行接入 H5 游戏引擎，负责渲染、输入和游戏循环。
验证交付通过测试、浏览器运行和打包校验后交付。

2.1 需求理解与 Spec 体系
结构设计
当前成果
未来工作

已完成固定范围内的结构化需求规格体系，用来描述竖版弹幕游戏的核心要素。

Spec 是机器可读取的游戏需求说明书。它不是开放文本，而是固定格式加可组合参数，方便后续模块选择、校验和生成。

gameType: vertical_bullet_hell player: movement: free_move enemy: attackPattern: spiral rules: scoring: defeat_enemy win: clear_stage lose: player_hp_zero

后续重点是把已经完成的工程底座扩展成完整的端到端自动生成闭环。
